# Automation Casebook

Case studies from my work building AI automations for small operations teams: email document filing, utility bill processing, monthly reporting and inbox triage.

Every build follows the same pattern: the AI classifies with a strict schema and a confidence score, anything below the threshold goes to a human review queue instead of being guessed at, and every decision is logged so it can be audited.

Read it here: https://camilagmuello-oss.github.io/automation-casebook/

All cases are anonymized. No client names, no identifying details.
